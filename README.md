# Cyberpunk RED for Foundry v14

An experimental implementation of the Cyberpunk RED Core rules for **Foundry VTT v14**.

## Compatibility

This system supports Foundry v14 only. Releases are experimental and may contain bugs.

Use a separate Foundry data folder and back up any existing worlds before testing migrations. The system ID is `cyberpunk-red-core`, so installing it replaces any existing system with that ID in the same data folder. Migrated worlds must not be opened with an older system or Foundry version.

## Installing

1. Choose a version from this repository's [GitHub releases](https://github.com/sachamm/cyberpunk-red-foundry-v14/releases), including prereleases for alpha builds.
2. Copy the link to the `system.json` file in that release's assets.
3. In Foundry v14's system installer, paste that link into **Manifest URL** and install.
4. Create a new world using the installed Cyberpunk RED system, or test a backed-up world in your separate data folder.

Use the manifest URL for the specific version you want. GitHub's `latest` download route does not select prereleases; to move between alpha versions, install the newer release's manifest URL explicitly.
